# État de la v0.1

Construite le 16 novembre 2026 à partir de cette architecture. Ce fichier dit ce qui marche, ce
qui diffère de l'architecture, et ce qui reste à faire.

## Ce qui marche (testé sur de vrais fichiers)

- **Projet et révisions** : le serveur est le seul à écrire ; chaque lot d'opérations est validé
  (Zod) puis enregistré comme révision (copie + journal). Undo, restauration d'une version.
- **Ingestion** : normalisation H.264 VideoToolbox à 30 i/s (le HEVC d'iPhone passe), WAV 48 kHz,
  transcription mot à mot whisper.cpp large-v3-turbo avec horodatage DTW, silences, plans,
  loudness, vignettes, poster, forme d'onde. Cache global par empreinte. 5 fichiers en 54 s.
- **Rendu** : segments calés sur les plans de la piste principale, empreinte relative au début du
  segment, son mixé à part (ducking de la musique, presets voix, loudnorm deux passes à -14 LUFS),
  recollage sans réencodage. Premier rendu à froid : 14 s de vidéo en 47 s ; après une retouche
  d'un titre : 1 segment sur 3 re-rendu en 8,7 s ; une carte de fin : 5,1 s.
- **Remotion** : worker chaud (bundle en cache, un seul Chrome), composition `Timeline`, grille
  `Look`, 12 composants (Title, TextPop, LowerThird, Callout, Highlight, Counter, Emoji,
  ProgressBar, Flash, Whip, ScreenshotShowcase, Captions).
- **Détourage** : helper Swift Apple Vision → WebM VP9 avec alpha, ~30 i/s, utilisé par
  `cutout: true` (texte derrière la personne).
- **Commentaires et versions** : épingle, zone, plage ; capture de l'image vue ; ancre de contenu
  qui suit le montage ; cycle brouillon → envoyé → en cours → corrigé → validé / rouvert ;
  passages modifiés calculés à partir des segments re-rendus.
- **Boucle Claude** : `claude -p` en stream-json avec seulement les outils Cezane, demandes de
  permission relayées à l'UI ; à la fin d'une session qui a modifié le montage, le serveur rend
  une nouvelle version. Un lot de 2 commentaires corrigé pour ~0,23 $ d'équivalent API (Sonnet).
- **Outils MCP** : overview, transcript, look, comment_context, edit, cut_silences, captions,
  audio_cleanup, graphics, import, capture, generate, canvas, render, reply, approve.
- **Interface** : Electron + React, à la FigJam, palette Cézanne : assets, lecteur image par
  image, outil commentaire, timeline, versions et A/B, fil d'activité de Claude, canvas tldraw
  avec cartes de génération, barre de prompt, workflows.
- **Génération** : Codex (images, gratuit sur l'abonnement ChatGPT, ~1 à 2 min), Claude (texte,
  abonnement), FAL (payant, clé dans le trousseau `cezane-fal` ; plafond de budget et
  confirmation). Provenance complète sur chaque asset.
- **Capture** : pages web dans Chrome (captures et défilement enregistré), simulateur iOS
  (captures et vidéo) ; provenance « capture ».

## Écarts avec l'architecture

- **Débruitage** : pas de DeepFilterNet ; les presets voix utilisent les filtres ffmpeg (afftdn,
  compresseur, égaliseur, de-esser).
- **Non faits** : LUT ; composants écrits par Claude (l'outil `graphics` liste le catalogue) ;
  outil MCP `workflow` (les workflows existent dans l'UI) ; lien clip ↔ élément du canvas
  (`canvasRef` est dans le modèle, pas encore branché) ; annulation des rendus devenus obsolètes ;
  éviction du cache global ; registre FAL lu depuis l'API (liste figée de 3 modèles).
- **Un seul montage par projet** pour l'instant.
- **Jobs en mémoire** : après un redémarrage du serveur, l'historique des jobs disparaît (les
  assets et les versions restent).

## Points connus

- whisper peut halluciner sur un audio sans voix (musique seule) ; à filtrer par la loudness ou
  la détection de voix.
- Les captures web de pages qui défilent dans un conteneur interne (pas la fenêtre) n'enregistrent
  pas le défilement.
- Le simulateur iOS est piloté par des outils externes ; Cezane enregistre et met en valeur.
- tldraw tourne en mode développement (filigrane) ; la licence hobby reste à confirmer.
